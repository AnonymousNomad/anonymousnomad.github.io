Nomadic Labs deliberately separates public website knowledge from private development systems.

ASK NOMADIC

Questions submitted to Ask Nomadic are sent to a server-side site guide backed by Cloudflare Workers AI. The guide is instructed to answer from the curated public project registry and not from private workstation data.

DO NOT SUBMIT SECRETS

Do not enter passwords, API keys, private client material, confidential documents, or other secrets into the public site guide. It is a public support interface, not a private operator channel.

CURRENT SITE BEHAVIOR

The current foundation does not include advertising scripts, payment forms, public user accounts, or third-party marketing analytics. Infrastructure providers may still process ordinary request metadata required to serve the site.
